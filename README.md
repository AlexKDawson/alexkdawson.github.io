# alexkdawson.github.io

Static site for First Proof Labs LLC. Plain HTML/CSS, no build step.

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

This repo is named `alexkdawson.github.io`, so GitHub Pages serves `index.html`
from the default branch automatically once Pages is enabled in repo settings.
